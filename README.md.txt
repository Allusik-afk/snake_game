# Змейка: Природа 🐍

2D-аркадная игра на Python (Pygame), созданная с помощью нейросетей.

## Особенности:
- 12 уровней с уникальными биомами
- Боссы с 4 HP, которые ускоряются при получении урона
- Магазин скинов и система достижений
- Сохранение прогресса

## Как запустить:
1. Установите Python.
2. Установите библиотеку: `pip install -r requirements.txt`
3. Запустите игру: `python snake.py`
